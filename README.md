# Freefall — support site

Support page and privacy policy for **Freefall**, a first-person skydiving game for
Apple Vision Pro. Served with GitHub Pages:

- Support: https://alanfeiyuchang.github.io/freefall-support/
- Privacy policy: https://alanfeiyuchang.github.io/freefall-support/privacy.html

Static HTML, one stylesheet, no build step. These are the URLs to give App Store Connect
(Support URL and Privacy Policy URL).
